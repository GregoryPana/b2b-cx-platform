# Shared Branding Assets

This folder is the source location for shared frontend branding assets used across the CX platform frontends.

Current assets:
- `online-survey.png` -> browser tab / bookmark icon and survey platform icon
- `cws-logo.png` -> Cable and Wireless Seychelles logo
- `cws-banner.png` -> Cable and Wireless Seychelles banner

Deployable frontends also keep runtime copies under their own `public/branding/` folders so Vite includes them in each built app.
