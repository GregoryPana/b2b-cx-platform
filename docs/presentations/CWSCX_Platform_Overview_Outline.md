# CWSCX Platform Overview Outline

## Audience
- new users
- non-technical users
- C-suite users
- operational and technical stakeholders

## Slide Flow

1. CWSCX gives one platform for customer experience surveys, governance, review, and reporting
2. CWSCX combines four user journeys into one controlled customer-experience operating platform
3. Three survey frontends and one governance dashboard cover the full customer-experience workflow
4. Users follow a simple flow from preparing visits to submitting and reviewing them
5. The platform separates tasks clearly by role so new users can adopt it quickly
6. A single-domain internal deployment keeps the user journey simple while centralising control
7. Monitoring, backups, and controlled deployments reduce operational risk
8. Mystery Shopper is moving to a separate DMZ deployment while the internal platform stays protected
9. Signed links, OTP, and link-plus-OTP each trade user friction against access control
10. CWSCX already provides a strong internal base and the next phase is controlled public expansion

## Core message

CWSCX is already a useful internal operational platform, and the next design decisions are about how to extend Mystery Shopper safely for external use without weakening the internal environment.
