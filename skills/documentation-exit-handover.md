# Documentation EXIT Handover Skill

## Purpose

Use this skill to ensure documentation, handover, and operational continuity artifacts are complete.

## Use When

- preparing handover
- updating EXIT content
- closing a deployment or workstream
- building documentation for new maintainers

## Rules

- keep `EXIT.md` at repo root
- keep environment-specific facts current
- record what is truly operational vs merely planned
- do not leave placeholder contacts or stale status text in production docs

## Process

1. update operational state
2. update ownership and escalation contacts
3. update backup and monitoring sections
4. update CI/CD and deployment model
5. review trackers against reality
